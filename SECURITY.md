## 🚨 Signaler une Vulnérabilité

La sécurité de ce projet est prise très au sérieux. Si vous découvrez une vulnérabilité de sécurité, merci de nous en informer de manière responsable.

### Comment Signaler

**NE PAS** ouvrir une issue publique pour les vulnérabilités de sécurité.

Au lieu de cela, veuillez :

1. **Envoyer un email privé** au mainteneur du projet
2. **Inclure les détails suivants** :
   - Description de la vulnérabilité
   - Étapes pour reproduire le problème
   - Versions affectées
   - Impact potentiel
   - Suggestions de correctifs (si disponibles)

### Ce à quoi vous pouvez vous attendre

- **Accusé de réception** : Nous accuserons réception de votre rapport dans les 48 heures
- **Évaluation** : Nous évaluerons la vulnérabilité et déterminerons sa gravité
- **Correction** : Nous travaillerons sur un correctif avec une priorité appropriée
- **Communication** : Nous vous tiendrons informé de l'avancement
- **Publication** : Une fois corrigée, nous publierons un avis de sécurité

### Processus de Divulgation

1. Le rapport de sécurité est reçu et assigné à un responsable
2. Le problème est confirmé et une liste des versions affectées est déterminée
3. Le code est audité pour trouver tout problème similaire potentiel
4. Les correctifs sont préparés pour toutes les versions encore supportées
5. Les correctifs sont publiés aussi rapidement que possible

## 🛡️ Bonnes Pratiques de Sécurité

Pour les contributeurs et utilisateurs :

- Gardez vos dépendances à jour
- N'incluez jamais de secrets ou de mots de passe dans le code
- Utilisez des variables d'environnement pour les informations sensibles
- Activez l'authentification à deux facteurs sur votre compte GitHub
- Revoyez les changements de code pour détecter les problèmes de sécurité potentiels
